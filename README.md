# Seismic reports from the Accelerographic Network of Panama (RAP)
This repository contains seismic events captured by the RAP and processed
by RAPID-SIS.

Some reports that might be of interest:
1. [July 8 2024](./2024/July/CHUS_titanSMA_2137_20240708_095400/) | [PDF report](./2024/July/CHUS_titanSMA_2137_20240708_095400/latex/CHUS_titanSMA_2137_20240708_095400.pdf)
2. [October 25 2025](./2025/October/CHUS_titanSMA_2137_20251025_234400) | [PDF report](./2025/October/CHUS_titanSMA_2137_20251025_234400/latex/CHUS_titanSMA_2137_20251025_234400.pdf)
3. [January 19 2026](./2026/January/CHUS_titanSMA_2137_20260119_034700) | [PDF report](./2026/January/CHUS_titanSMA_2137_20260119_034700/latex/CHUS_titanSMA_2137_20260119_034700.pdf)

In each event directory you will find the relevant plots,
plain text files with the event points and a JSON file with
all the relevant values of the event (e.g. PGA).
These files and values are used for to generate the PDF report.
